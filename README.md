## 這是什麼

事務所每次現場查驗回來，都要做同一件事：把幾十張照片跟平面圖對起來，
標出「這張是在哪裡拍的」，再排成一張看得懂的圖說紀錄。
這件事沒有技術難度，但很花時間，而且排到最後往往版面又擠又亂。

**圖說紀錄產生器**就是把這段流程做成一個網頁工具：
匯入現場照片與平面圖 → 在平面圖上點出每張照片的位置 → 寫說明、畫標記 →
一鍵產出大圖報告。平面圖置中，照片環繞四周，每張照片以引線連回它在平面圖上的位置，
說明文字在照片下方。紙張 A0 / A1 / A2 / A3 可選，預設 A3 橫式，
排版是程式算出來的（會自動決定照片要放幾欄、要不要排到上下），不合意也能整個接手用拖的調。

這份專案是 **2026 年 8 月高雄建築師公會 AI WORKSHOP 的示範案例** ——
講的不只是「這個工具能做什麼」，而是**一個事務所的實際困擾，怎麼被拆解成
三個畫面、再交給 AI 一段一段做出來**。首頁那份簡報就是當天的完整內容，
最後一頁還附了三題小練習，各有一句可以直接複製貼給 AI 的需求描述，
照著跑就能自己替這個工具加功能。

## 幾個或許值得一提的地方

- **純前端，照片不會離開這台電腦。** 沒有後端、沒有帳號、不需要網路連線。
  資料存在瀏覽器自己的 IndexedDB 裡，要備份就匯出成一個 `.sitelog` 檔帶走。
- **報告是用瀏覽器列印產生的，不是截圖。** `@page` 直接指定實際紙張尺寸，
  文字、引線、圖框全是向量，印出來線條銳利、PDF 裡的文字還能搜尋。
- **標註存成 SVG 不燒進點陣圖**，所以事後還能修改、移動、刪除；
  **裁切是非破壞性的**，原始影像一個位元組都不動，隨時按「全圖」還原。
- **引線不會交叉** —— 照片依它最靠近平面圖的哪一邊分派，同一邊再依沿邊座標排序後對位。
- 平面圖可以匯入多張（各樓層分頁），支援影像與 PDF；設好比例尺之後能以 1:100 之類的真實比例出圖。

## 課程用途，歡迎自行取用、修改

拿去改、拿去教、拿去接自己事務所的流程都可以。內附的示範資料
（平面圖與 14 張施工查驗照片）為 **AI 生成的教學素材，不是實際工程紀錄** ——
照片裡的施工缺失是刻意做出來給人練習「找錯」用的。

## 怎麼開始

**線上直接試**：<https://thinklab-architects.github.io/KAAwokshop-photo_plan_locator/app/>
開起來就能用，資料存在你自己的瀏覽器裡。

**下載回本機**：右上角 Code → Download ZIP，解壓縮之後雙擊
`app/開啟圖說紀錄產生器.cmd`，瀏覽器就會自己打開。收工時雙擊
`app/關閉圖說紀錄產生器.cmd`。**不需要安裝 Python 或 Node** ——
背景那支伺服器是用 Windows 內建的 .NET `HttpListener` 寫的，
只是把資料夾裡的檔案發給瀏覽器，不對外開放。

第一次開啟會自動放進兩份示範紀錄（二層住宅的一樓與二樓，共 14 張查驗照片，
位置點、拍攝方向、說明與標註都已填好），可以直接按「產生報告」看結果。
不需要的話整份刪掉就好，刪掉之後不會再自己出現。

完整說明（架構、排版演算法、實作上的取捨、為什麼移除 DWG 直接匯入）
在 [`app/README.md`](app/README.md)；圖文操作教學在 `app/docs/使用說明.html`，
程式裡右上角的「使用說明」也是開這一份。
