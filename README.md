# 圖說紀錄產生器 · KAA AI WORKSHOP

> **這是吳欣儒開發的「高雄建築師公會 KAA AI WORKSHOP」示範檔案。**
>
> 課程用途，歡迎自行取用、修改。內附的示範資料（平面圖與 14 張施工查驗照片）
> 為 AI 生成的教學素材，不是實際工程紀錄。

這個 repo 有兩個東西：

| 位置 | 內容 |
|---|---|
| [`index.html`](index.html) | **演講簡報** —— 網站首頁。左右方向鍵翻頁，<kbd>O</kbd> 看總覽，<kbd>F</kbd> 全螢幕 |
| [`app/`](app/) | **圖說紀錄產生器** —— 簡報裡示範的那個工具，可以直接開來用 |

## 工具是什麼

匯入現場照片與平面圖 → 在平面圖上點出每張照片的位置 → 寫說明、畫標記 →
一鍵產出大圖報告。平面圖置中，照片環繞四周，每張照片以引線連到它在平面圖上的位置。
紙張 A0 / A1 / A2 / A3 可選，預設 A3 橫式。

**純前端，照片不會離開這台電腦。** 沒有後端、不需要網路連線，
唯一的程式庫（PDF 用 pdf.js）也放在本機的 `app/vendor/`。

## 怎麼開始

**線上直接試**：開 `app/`（本站的 `/app/` 路徑）就能用，資料存在你自己的瀏覽器裡。

**下載回本機**：右上角 Code → Download ZIP，解壓縮之後雙擊
`app/開啟圖說紀錄產生器.cmd`，瀏覽器就會自己打開。收工時雙擊
`app/關閉圖說紀錄產生器.cmd`。不需要安裝 Python 或 Node。

第一次開啟會自動放進兩份示範紀錄（二層住宅的一樓與二樓，共 14 張查驗照片，
位置點、拍攝方向、說明與標註都已填好），可以直接按「產生報告」看結果。

完整說明（架構、排版演算法、實作上的取捨）在 [`app/README.md`](app/README.md)；
圖文操作教學在 `app/docs/使用說明.html`，程式裡右上角的「使用說明」也是開這一份。
